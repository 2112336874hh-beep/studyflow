# PRD — StudyFlow

작성일: 2026-11-01 · 신규 중간고사 프로젝트

## 문제와 대상

여러 강의의 과제와 복습을 관리하는 대학생은 해야 할 일과 마감일이 흩어져 있으면 우선순위를 정하기 어렵다. 한 화면에서 기록하고 완료를 확인하는 개인용 앱을 만든다.

## 목표

- 로그인 없이 할 일을 등록할 수 있다.
- 날짜와 우선순위로 지금 할 일을 고를 수 있다.
- 완료한 수와 전체 수를 기반으로 진행 상황을 알 수 있다.
- 새로고침 후에도 현재 브라우저에서 데이터를 유지한다.

## 사용자 흐름

앱 열기 → 새 할 일 → 이름·날짜·선택 정보 입력 → 저장 → 검색/정렬 → 완료 표시 → 진행률 확인.

## 기능 및 수용 기준

| ID | 기능 | 수용 기준 |
| --- | --- | --- |
| F01 | 생성 | 이름과 유효한 날짜가 있어야 저장한다. 공백 이름을 거부한다. |
| F02 | 수정 | 기존 항목을 불러와 이름·과목·날짜·우선순위·메모를 변경한다. |
| F03 | 삭제 | 확인 창에서 취소하면 유지하고 확인하면 삭제한다. |
| F04 | 완료 전환 | 한 번 누르면 완료, 다시 누르면 진행 중으로 돌아간다. |
| F05 | 통계 | 전체 수 = 진행 중 + 완료. 완료율 = 완료 수 / 전체 수 × 100 반올림, 빈 목록은 0%. |
| F06 | 탐색 | 제목·과목 검색과 상태 필터를 함께 적용한다. 오늘 마감 보기는 완료 여부와 무관하게 오늘 날짜를 기준으로 한다. |
| F07 | 정렬 | 미완료를 먼저 표시하고, 선택한 기준으로 정렬한다. |
| F08 | 기한 표시 | 기기 로컬 날짜 기준으로 미완료 항목의 오늘 마감/기한 초과를 구분한다. |
| F09 | 저장 | localStorage 자동 저장, 실패 시 알림. 동일 주소의 다른 탭 저장 변경 반영. |
| F10 | 백업 | 버전 1 JSON을 내보내고 검증한 파일만 병합한다. 같은 ID는 중복 추가하지 않는다. 2MB 초과는 거부한다. |

## 비기능 요구사항

- 모바일/데스크톱 화면, 레이블이 있는 입력과 버튼, 키보드 포커스.
- 사용자 입력은 텍스트로 출력하여 HTML로 실행하지 않는다.
- 외부 패키지와 서버 DB 없이 정적 파일로 실행.
- 작업 데이터나 인증 정보를 GitHub에 포함하지 않는다.

## 데이터 모델

할 일: `id`, `title`(1~100자), `course`(0~40자), `due`(YYYY-MM-DD), `priority`(high/medium/low), `notes`(0~1000자), `done`(boolean), `created`(밀리초 timestamp).

브라우저 키: `studyflow.tasks.v1`. 새 브라우저에는 예시 4개를 최초 한 번만 생성한다. 사용자가 모든 항목을 삭제한 빈 목록은 새로고침해도 유지한다.

## 제외 범위

회원가입, 계정별 동기화, 알림, 팀 공동 편집, 실제 학교 시스템 연결은 이번 버전의 범위에 포함하지 않는다.
