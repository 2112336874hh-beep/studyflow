## 수동 재현 체크리스트

아래는 전체 검증을 위한 절차이며, 확인 결과가 위 표에 없으면 아직 검증 완료로 간주하지 않는다.

1. 이름을 비우고 저장 → 등록 차단. 공백 이름도 차단.
2. 새 항목을 추가 → 전체·진행 중 +1, 완료율 재계산.
3. 완료 전환 → 완료 +1, 진행 중 -1. 다시 누르면 복원.
4. 항목 수정 → 변경한 값만 반영, 기존 완료 상태 유지.
5. 삭제 취소 → 유지. 삭제 확인 → 삭제.
6. 제목/과목 검색 → 일치하는 항목만 표시, 없는 검색은 안내.
7. 진행 중/완료 필터, 오늘 마감 보기, 세 가지 정렬 확인.
8. 새로고침 → 저장한 내용 유지.
9. 모든 항목 삭제 후 새로고침 → 빈 목록 유지, 예시 재생성 없음.
10. JSON 내보내기 후 다시 가져오기 → 같은 ID가 중복되지 않음.
11. 잘못된 JSON 또는 2MB 초과 파일 → 오류 메시지, 기존 항목 유지.
12. 390px 모바일 화면에서 가로 넘침, 버튼, 모달 확인.

## 알려진 한계

- 다른 기기 및 다른 주소 간 동기화 없음.
- 브라우저 저장이 차단되거나 용량이 부족하면 저장 실패 안내가 표시됨.
- 운영체제 알림이나 이메일 알림 없음.
- 외부 글꼴을 불러오지 못해도 시스템 글꼴로 실행됨.
- GitHub 업로드는 원격 저장소의 커밋과 파일 목록을 확인한 뒤 완료로 판단.
